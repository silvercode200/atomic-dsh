## 2. Приоритет жертвенности полей (первый уходит первым) — УТВЕРЖДЁН юзером

```
sessionId → title → spend → cost → tokens → cache → tps → comp
→ mode/effort → git → cwd(компакт) → timer → ctx → model
```

Правила: при нехватке ширины поля уходят С ЦЕЛЫМИ значениями слева направо
по списку; после каждого ухода строка перекомпонуется; минимум (инвариант 8)
не нарушается никогда. **Особый случай (решение юзера): title (название
папки) при нехватке места СЖИМАЕТСЯ (усечение с …), а не дропается —
уходит целиком только когда места нет даже для усечённой формы.**

## 3. Канон остальных поверхностей

- **Стрим** (inline и fullscreen): 0 спейсер-зон, 0 дрожи, контент не
  «опускается»; скольжение при sticky — легитимно. Серию кадров смотреть
  детекторами blank/flicker (suite v2), не глазами.
- **Скроллбек** (только inline): история панели = поток контента (сообщения,
  разделители turn'ов). Хром (рамки ввода, статус-ряды, промпты) в истории
  запрещён — один живой кадр внизу. Ресайз не оставляет сломанных рамок.
- **Слэш-меню**: полный список команд виден и запускается; на любой ширине
  ≥40 читаем. **Ответ юзера по E2: при вводе '/' видно «пусто и первая
  буква»** — меню не рендерится ВООБЩЕ в его среде (zellij/WezTerm), хотя в
  tmux-парити рендерится с корректными цветами → гипотеза: оверлей-репейнт
  в inline уходит в историю/мимо живого кадра (механизм-родственник E1);
  эскалация — zellij-бинарь на Colab VM.
- **Настройки/хабы**: **язык — весь EN (решение юзера)**; сейчас смесь
  EN-нативных и RU-хаб-групп — E3. Логичный порядок групп, каждый тумблер
  реально влияет на рендер или удалён. Мёртвые в inline тумблеры
  (trajectory/activity/shortcutHint — supplemental-ряд не монтируется в
  inline) либо работают в inline, либо помечены и спрятаны.
- **Демо-режим настроек/тем/эффектов (требование юзера, новое)**: при
  переключении темы в пикере — ПОЛНЫЙ живой превью-текст ниже списка, где
  видны ВСЕ места проявления темы (статус-бар, рамка ввода, тексты,
  кнопки/чипы, дим-ряды, гейджи, powerline-сегменты). По остальным
  эффектам и настройкам в /settings — то же: пояснение значения каждой
  настройки и типа эффекта + ПРИМЕР рядом (как выглядит включено/выключено
  или каждое значение). Не «пикер из названий», а самодокументирующийся
  интерфейс.
- **Субагент-карточки**: поля целиком или дроп; 0 пустых waterfall-рамок;
  карточки рендерятся для ВСЕХ путей спавна (инструмент subagent И
  run_code/code-dispatch — сегодня второй путь не рендерит карточки, E8).
- **Тексты ленты**: все строки видимы (fg ≠ bg, dim-ряды проверяются на
  фоне юзера); переносы без аномальных щелей между словами (E6 — кандидат
  рассинхрон ширины глифов ink vs шрифт WezTerm).
- **/theme**: применение живое; клавиши не утекают (C4-остаток); пикер
  читаем на узких.
- **Компакция**: фаза видима (спиннер/строка «Compacting…»), завершение —
  строкой; сегодня toast 4с при окне ~52с и нулевая индикация события (C5).
- **Обрыв стрима**: stop_reason length/max-tokens → авто-continue (сегодня:
  молчаливый notice «turn max-tokens» и стоп, D-b1); stall-детектор для
  тихих обрывов (D-b).
- **Todo-панель**: оформление стабильно; перерисовки не двоят список в
  скроллбеке (E7 — семейство E1).

## 4. Верификационная процедура (как проверяется канон)

1. **Golden-сьют** = этот канон детекторами, юзер-парити (inline АССЕРТЕН,
   конфиг юзера, тема, геометрия юзера + свип + случайные): прогон на КАЖДОМ
   изменении стека. Сьют dsh-tui-inline.yaml (готов) + расширение до golden
   (узел C).
2. **Бисекция**: деплой-таргеты patches:<ref> — любая регрессия ловится
   указанием точного патча-виновника (узел A2b, идёт: pristine-прогон).
3. **Сдача**: до/после кадры на геометриях юзера + твой чек-лист. «Сделано»
   = твоё подтверждение глазами, не мой вердикт (узел F).

## 5. Решения юзера (2026-09-21) — закрытые вопросы

1. Порядок жертвенности — **согласен**; title на 2-м месте, при нехватке
   места **сжимается**, а не дропается.
2. Инвариант 8: какая метрика остаётся на узких (⚡ vs comp) — **настройка
   эфф. плагина (hub-effects)**.
3. E2 при вводе '/': **«пусто и первая буква»** — меню не рендерится в среде
   юзера вообще (см. §3 Слэш-меню: эскалация zellij на VM).
4. Язык настроек: **весь EN**.
5. Демо: полный превью-текст при переключении темы + пояснения всех настроек
   и типов эффектов с примерами рядом (см. §3 Демо-режим).
